Project support

For bug reports, feature requests, or questions, open an issue in the MesTok GitHub repository:

MesTok Support on GitHub

Please protect your privacy. Do not post passwords, TikTok login codes, private messages, phone numbers, or other sensitive personal information in public issues.

Before reporting a problem

  • Include your Android version and phone model if relevant.
  • Describe the steps that caused the issue.
  • Share logs only after checking that they contain no personal or account information.
